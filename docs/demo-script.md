# Demo script (3 minutes, real-product arc)

Dashboard: https://museaiteam-api.juarezjaramillo.workers.dev
Tour page: https://museaiteam-api.juarezjaramillo.workers.dev/site

## Setup (before judges arrive)

- Founder org signed in; trial banner shows 14 days
- All 6 providers connected on the org; Notion parent page saved in Setup;
  HubSpot portal has ≥1 ticket; Shopify is a dev store with a showcase
  product picked; Slack app has channels:history, Shopify has
  read_orders + products scopes (reconnect after scope upgrades)
- One rehearsed goal exists (preapprove, daily): shows timeline +
  metric chart with ≥2 points on the goal page
- Backup: full founder pass recorded on video (goal → run → approval
  → revision → checks → billing); kill switch + revert rehearsed

## The 3 minutes

- **0:00–0:20 — Goal.** Goals tab: a real goal with squad, schedule,
  approval mode, metric chart. "You assign outcomes, not tasks."
- **0:20–1:00 — Debate + approval.** Run history shows the debate:
  proposals, votes, manager ruling. Pre-approve gate: the run waited
  for a human. Approve it live (or show the approval already decided
  in the Approvals inbox).
- **1:00–1:50 — Ship.** Six artifacts land live, not screenshots: GitHub
  PR (merged as-is), Linear epic with sub-issues, Slack thread update,
  Shopify targeted discount inside the cap, HubSpot triage + follow-up,
  Notion decision page + run log. Open two in their real homes.
- **1:50–2:20 — Revision + learning.** Request-changes note on one
  artifact → revision child run re-shipped it. Thumbs up/down on
  artifacts → playbook drafts → approved tactics the team follows.
- **2:20–2:45 — Long-term.** Timeline shows weekly checks pulling the
  metric (time-compressed in rehearsal); overdue flags but keeps
  working. Hires tab: per-hire runs/proposals/shipped/ratings/spend.
- **2:45–3:00 — Close.** Billing tab: $499/worker anchored vs a human
  hire, fair-use meter, CSV audit export. Kill switch + one-click
  revert; ask.

## If it breaks live

1. Hit Kill, narrate it as a feature ("human halts any run")
2. One-click revert the bad action from the audit log
3. Roll the backup video from the matching timestamp; keep narrating
