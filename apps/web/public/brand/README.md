# Muse AI Team brand assets

Concept D ("council chamber"): six ink nodes in porthole rings, triple
blue links to a shaded gem hub in a wavy surround, triangular mesh,
ticked orbit rings with three satellites. Palette matches the
dashboard: ink `#1a2333`, accent `#1f5eff`, light backgrounds only.
The full mark is used at every size (no simplified variant).

## Files

`svg/` — masters. `muse-ai-team-mark.svg` (the mark),
`muse-ai-team-mark-mono.svg` (all-white mark for Linear's directory),
`muse-ai-team-lockup.svg` (mark + wordmark).

`png/` — exports. Generic (`mark-512/128/32`, `favicon-32/16`,
`lockup-1200` for OG) plus one app icon per store, all using the same
mark:

| File | Spec it satisfies |
|---|---|
| `appicon-slack-512.png` | Slack 512x512, square, unrounded (Slack rounds) |
| `appicon-github-200.png` | GitHub App/OAuth badge, >=200px, <1MB, transparent |
| `appicon-linear-256.png` | Linear OAuth `iconUrl`, >=256px |
| `appicon-linear-directory-320.png` | Linear directory color icon, 320px |
| `appicon-linear-directory-320-mono.png` | Linear directory white icon, 320px, transparent |
| `appicon-notion-512.png` | No published spec; 512px generic |
| `appicon-hubspot-512.png` | No published spec; 512px generic |
| `appicon-shopify-1200.png` | Shopify 1200x1200 with padding, PNG |
| `appicon-atlassian-144.png` | Atlassian Marketplace logo, 144px |

Sources: Slack app-design + marketplace guidelines, GitHub custom-badge
docs, Linear OAuth manifests + integration directory, Notion
public-connections, HubSpot app-configuration, Shopify submit-for-review,
Atlassian marketplace-presence docs.

## Notes

- Wordmark uses the system sans stack (Helvetica Neue / Arial, 800
  weight), not outlined paths — keep for screen use.
- The mark is generated by `build-mark.mjs` (kept with the working
  files, not shipped); regenerate PNGs from `svg/` with any SVG
  rasterizer (these were rendered with `sharp`).
