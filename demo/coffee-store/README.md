# Tres Cumbres Coffee Co. (fictional demo store for the Muse AI Team hackathon video)
Photos made with Muse Image (`muse-image-1.0`); re-run with `node make-images.mjs` (needs `META_MODEL_API_KEY`).
CSVs are generated from `products.json` with `node make-csv.mjs`.
Import `shopify-products.csv` by hand into a Shopify development store.
Import `hubspot-tickets.csv` by hand into a HubSpot test portal.
Everything in this folder is fictional; no real customers or orders.
